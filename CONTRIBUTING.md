# Contribuindo

1. Descreva a mudança pretendida e mantenha cada alteração focada.
2. Para indicadores, registre fonte primária, link específico, data de referência, unidade e data de consulta. Não apresente estimativas como dados oficiais sem identificação.
3. Execute `python3 -m unittest discover -s tests -v` e teste manualmente no navegador, incluindo telas menores e navegação por teclado quando houver alterações na interface.
4. Abra uma solicitação de alteração para revisão antes da integração à branch de publicação.

Não inclua senhas, chaves de API ou dados pessoais no repositório. Evite arquivos gerados e dependências baixadas; documente qualquer nova dependência e suas condições de uso.

Os testes existentes são verificações básicas, não substituem revisão visual, validação das fontes ou testes de acessibilidade.
